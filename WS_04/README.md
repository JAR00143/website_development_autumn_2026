## Workshop 4: Page Layout Techniques

Restructured the webpage using semantic HTML5 elements and implemented responsive, modern CSS layout systems.

* **Task 1: Use Semantic Elements** – Organized the page layout using `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` tags, adding internal anchor navigation links (`#about`, `#courses`, `#contact`) for improved structure and accessibility.
* **Task 2: Create a Grid Layout** – Built a two-row, three-column two-dimensional grid (`.grid-container`) using `display: grid`, `grid-template-columns: repeat(3, 1fr)`, and `grid-gap: 10px`.
* **Task 3: Create a Flexbox Layout** – Created a horizontal one-dimensional row of content boxes (`.flex-container`) using `display: flex`, evenly spaced with `justify-content: space-around` and vertically centered via `align-items: center`.
* **Task 4: Add Media Queries** – Implemented responsive breakpoints (`max-width: 600px` and `min-width: 601px`) on `.responsive-box` so its background color dynamically adapts to viewport width changes.
* **Task 5: Validate Your HTML and CSS** – Verified markup and stylesheet syntax compliance using the W3C Validation extension in Visual Studio Code and resolved reported issues.
